## Hi there! 👋 I'm Christian Pecson, a Full Stack Engineer building real-world mobile and web products.

🚀 With 7+ years of experience across fintech, enterprise, and SaaS, I design, build, and ship products people actually use — native iOS, native Android, cross-platform, and full-stack. My apps have passed **100k+ downloads**, and I've shipped at **6 companies**, from blockchain startups to global SaaS.

📱 Currently a **Mobile Application Developer @ tawk.to**, working across the hybrid mobile app — designing, coding, testing, and releasing features against strict coding standards and review cycles.

🛠️ My tech toolkit includes TypeScript, React, NextJS, Angular, NodeJS, NestJS, and Ionic/Capacitor, with native work in Swift and Android. On the backend I reach for Go, Postgres, and AWS Lambda, and I lean on Nx for monorepos.

🔐 Lately I've been deep in secrets and credential security — building MeowPass, an encrypted secret manager with a CLI-first workflow and an AI credential gateway that gives agents scoped, brokered access instead of raw API keys.

🧠 When it comes to problem-solving, I like breaking complex technical matters down into clear, digestible pieces, which lets me work comfortably across the gap between engineering and product.
